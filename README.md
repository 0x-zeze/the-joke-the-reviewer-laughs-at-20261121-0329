# The joke the reviewer laughs at

A make.fun entry for the bounty
[the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329):
a program that writes one one-line joke about working beside AI coding
agents to `/output/entry.txt`.

The joke (118 characters, drafted in the build session):

> I asked my coding agent to review its own pull request; it approved in four seconds and told me to stop micromanaging.

The setup is the daily reality of reviewing agent-written code; the
punchline lands at the end, with the roles reversed — the agent, not
the human, is the one complaining about micromanagement.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.txt (one line, deterministic, no network)
```
